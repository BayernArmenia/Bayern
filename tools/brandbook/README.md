# Брендбук: как править

`BAYERN Brand Book (standalone).html` — самодостаточный файл на 1 МБ: его можно открыть в любом
браузере без интернета. Внутри он устроен как самораспаковывающийся архив:

| Блок в файле | Что лежит |
|---|---|
| `<script type="__bundler/template">` | вся вёрстка брендбука — **одной строкой JSON** |
| `<script type="__bundler/manifest">` | логотипы, шрифты IBM Plex и React — base64 |
| `<script type="__bundler/ext_resources">` | ссылки на React, подменяются на вложения из манифеста |

Править standalone-файл руками нельзя: вёрстка — это одна строка на 120 КБ с экранированными
кавычками. Поэтому правим через распаковку.

## Цикл правки

```bash
node tools/brandbook/unpack.mjs    # standalone → tools/brandbook/template.html
# правим template.html как обычный HTML
node tools/brandbook/pack.mjs      # template.html → standalone
```

Проверить, что сборка ничего не ломает:

```bash
node tools/brandbook/pack.mjs --check
```

Должно ответить «круг сходится: файл байт в байт тот же».

**Подводный камень.** При сборке `/` в закрывающих тегах экранируется в `/`. Без этого первый
же `</script>` внутри строки закроет блок `__bundler/template` и файл развалится. Это делает
`pack.mjs`, вручную повторять не нужно — но и убирать эту строчку нельзя.

## Как устроен template.html

Страница = `<section class="page" data-screen-label="NN Название">`, формат A4, стили инлайновые.
У каждой страницы в подвале свой номер:

```html
<span>BAYERN BRAND BOOK · {{ version }}</span><span>07</span>
```

`{{ version }}` подставляется из пропса `version` внизу файла (сейчас `v1.1 · 2026`).

Добавили страницу — не забудьте:

1. перенумеровать `data-screen-label` и номера в подвалах у всех следующих страниц;
2. обновить диапазоны на странице «02 Contents»;
3. поднять версию документа.

`<image-slot>` — плейсхолдеры под логотипы вендоров. Браузер ищет для них
`.image-slots.state.json`; файла нет, в консоли будет 404 — так и задумано, на вёрстку не влияет.

## Файлы и git

`BAYERN Brand Book (standalone).html` и распакованный `template.html` — в `.gitignore`:
репозиторий публичный, а брендбук помечен как внутренний документ. В git лежат только скрипты
и этот README. Оба файла живут локально; `template.html` в любой момент восстанавливается
из standalone-файла командой `unpack.mjs`.

Если репозиторий станет приватным и брендбук нужно хранить в git — уберите обе строки из `.gitignore`.
